# 2048 — ひと息、ひと手。

iPhoneで遊ぶための、広告なし・自動セーブ付き2048。フレームワーク、実行時の外部依存、広告、解析ツール、サーバーデータベースは使用していません。

## 遊ぶ

**[2048で遊ぶ](https://usaginchaku.github.io/pocket-2048/)**

Safariで公開URLを開き、共有メニューの「ホーム画面に追加」を選びます。初回は通信できる状態で開き、ヘルプの「オフラインでも遊べる準備ができています」を確認してください。

- 盤面を上下左右にスワイプ。PCでは矢印キー／WASDでも操作できます。
- 「ボタンで操作」を開くと、方向ボタンを使えます。
- 毎手の完了時、アニメーションより先に盤面・スコア・ベスト・直前の盤面を保存します。
- 「1手戻す」は一度だけ。戻した後に動けば、また直前の一手を戻せます。
- 「はじめから」は確認付き。ベストスコアは残ります。
- 2048に到達した後も、続けて遊べます。
- 初回のキャッシュ完了後はオフラインで起動できます。

記録はそのブラウザの`localStorage`内にあります。Safariとホーム画面アプリや、別端末間での同期はありません。サイトデータ削除やOSによるデータ消去で記録は失われます。保存を拒否された場合もプレイは可能ですが、画面に保存できないことを表示します。

GitHub Pages上のアプリは公開サイトとして配信されます。プレイ記録は端末内に保存され、GitHubや他の利用者には送信されません。

## GitHub Pagesで公開

1. このソースをGitHubリポジトリの`main`ブランチへプッシュします。
2. リポジトリのSettings → Pages → Build and deploymentで、Sourceを**GitHub Actions**に設定します。GitHubのプランによっては、Pagesの利用に公開リポジトリが必要です。
3. Actions → **Deploy to GitHub Pages** → Run workflowで`main`を選んで実行します。以後は`main`へのプッシュで自動更新されます。
4. ワークフローのPublishジョブが成功した後、Settings → Pagesの公開URLをSafariで開きます。リポジトリ名が`pocket-2048`の場合、通常のURLは`https://<GitHubユーザー名>.github.io/pocket-2048/`です。

ワークフローは構文チェック、ルール・保存・サービスワーカーのテスト、ChromiumとWebKitでのブラウザテストを通してから、`dist/`を公式のGitHub Pages Actionsで配置します。アプリはビルド不要です。リポジトリ内容の書換え権限は使わず、公開ジョブにPagesとOIDCの権限を付与しています。

初回はオンラインで開いてオフラインの準備完了を確認し、Safariの共有メニューから「ホーム画面に追加」してください。公開先のドメインが変わると保存領域も別になるため、別の公開先で遊んだ記録は自動では引き継がれません。

## ローカルで実行

Node.js 22以上を推奨。ゲームの実行にパッケージのインストールやビルドは不要です。

```sh
npm start
```

`http://localhost:4173` を開きます。iPhoneからサービスワーカーを使う場合はHTTPSのホストが必要です。LANのHTTPアドレスではオフライン機能は有効になりません。

## 検証

```sh
npm test
npm run check
npm ci
npx playwright install chromium webkit
RUN_WEBKIT=1 npm run test:browser
```

- ルール：4方向の合体順序、1手での二重合体禁止、無効手、勝利／終了、乱数盤面の保存則。
- 保存：再開、Undo、ベストスコア、壊れたデータ、容量不足・保存拒否。
- オフライン：キャッシュ、スコープ、更新時の既存ゲーム保持。
- ブラウザ：操作、画面サイズ、再読込、各ダイアログ、勝利後継続、オフライン再起動。

## 構成

| ファイル | 役割 |
| --- | --- |
| `dist/engine.js` | ブラウザに依存しない2048ルール |
| `dist/storage.js` | バージョン付き保存とデータ検証 |
| `dist/app.js` | 操作、表示、アニメーション、自動セーブ |
| `dist/sw.js` | オフライン用サービスワーカー |
| `dist/manifest.webmanifest` | ホーム画面アプリの設定 |
| `.github/workflows/pages.yml` | 検証後にGitHub Pagesへ自動公開 |
| `test/` / `e2e/` | ルール・保存・サービスワーカー／ブラウザの自動テスト |

## 配置と更新

`dist/`を任意のHTTPS静的ホストへ配置できます。すべてのURLは相対指定なのでサブディレクトリ配信にも対応しています。

アプリのファイルを変更して公開するときは、`dist/sw.js` の `VERSION` を必ず更新してください。新バージョンは開いているゲームを強制終了せず、既存のアプリウィンドウをすべて閉じてから有効になります。`sw.js`には長期固定キャッシュを設定しないでください。

アイコンの再生成にはPythonとPillowを使います。`python scripts/generate-icons.py` を実行してください。

2048のゲームルールに基づく独自実装です。
